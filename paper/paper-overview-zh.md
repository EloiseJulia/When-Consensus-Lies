# When Consensus Lies —— 论文详解（中文）

> 论文标题：**When Consensus Lies: Fake Redundancy in Multi-Model AI Systems**
> 目标会议：CSCW / PACM HCI（匿名提交稿）
> 本文档基于论文正文（`paper/tex/consensus-lies.tex`）整理，数字均取最终确认值（Study 2 干预为完整 972-cell）。
> 一句话概括：**当协作系统把"多个 AI 模型的一致"当作独立佐证时，这种一致可能是"假性冗余"——共享同一份残缺输入的模型会共享同一个盲点，静默地一起犯同一个错。**

---

## 1. 背景与动机

### 1.1 现象：协作系统在"聚合多个 AI 判断"
越来越多的协作/决策支持系统不再只问一个模型，而是**同时问多个模型并聚合结果**——展示它们的一致、给出共识裁决，或合成一个答案，把这种"多模型一致"当成信心的来源。这一模式在**同题多模型界面（same-prompt multi-model interfaces）**里已经落地，例如 **ChatHub**（把一个 prompt 同时发给 GPT、Claude、Gemini 并排展示）等工具，普遍把"多模型并行"作为一种**认知卖点**（"多个视角 → 更可信"）。

### 1.2 那条没人明说、却人人默认的推理链
> **模型多样性 ⇒ 视角多样性 ⇒ 独立佐证 ⇒ 更高可信度**

这条链借用的是一个古老而具体的思想（孔多塞陪审团定理、群体智慧）：**聚合只有在被聚合的判断"有能力"且"误差足够独立"时才提升可靠性**。同题多模型界面继承了这个"担保"，却也继承了它的**前提条件**——而"把一个 prompt 发给五个模型"是否真的产生五个**独立**的任务解读，远非显然。

### 1.3 核心主张
本文证明这条链的**中间环节会断裂**：
> **模型多样性不必然等于证据多样性（model diversity is not necessarily evidence diversity）。**
> 当多个模型共享同一份（可能残缺的）输入时，它们会**共享同一个盲点**。

而且这种失败是**静默的**——界面上的"4/4 模型一致"无法把"真一致"和"假一致"区分开。

---

## 2. 核心概念

| 概念 | 含义 |
|---|---|
| **Fake redundancy（假性冗余）** | 表面上的冗余（多个 agent 一致）在共享信息边界下**不构成独立佐证**，因为所有 agent 继承了同一份对任务的有损表示。 |
| **Convergent delusion / CD（收敛性错觉）** | 主指标：一组 agent 中，落在**同一个错误（枚举内）解读**上的比例。只有当大家**一致地错**（而非各自随机错）时才高。 |
| **Interpretive monoculture（解释单一化）** | 名义上异质的模型，在关键上下文统一缺失时，形成一种"解释上的单一栽培"。 |
| **Silent failure（静默失败）** | CD 很高时，模型几乎不主动提出澄清/弃权（abstention ≈ 0.03%），共识里没有任何内部预警。 |
| **Latent-premise ambiguity（潜在前提歧义）** | 答案暗中依赖一个未言明、却决定结果的前提；模型对此"自信地猜"。 |
| **Danger quadrant（危险象限）** | 低 seed 熵（模型自信一致）× 高 context 熵（一旦钉住潜在前提答案就翻）——正是语义熵看不见、却最危险的区域。 |

## 3. 相关工作（按"本文检验的假设"组织，而非按技术）

- **聚合何时有用：独立性及其侵蚀。** 孔多塞定理/群体智慧的乐观结论依赖**能力 + 足够独立**；集成学习同样表明"集成误差 = 平均个体误差 − 多样性项"，当成员相关时存在**共同误差下界**。社会影响会在**不提升准确率**的情况下削弱多样性、导致对错误的自信收敛。
- **Grounding 与协作中的信息边界。** 把"保留的 prompt"视作 agent 的共享信息环境，"被删的关键澄清"是一道 **grounding-resource boundary**；下游的一致无法修复上游的 grounding 失败。
- **对聚合式 AI 建议的过度依赖。** 人们常在 AI 出错时仍接受其输出；解释/置信度展示未必有用；"5/5 一致"正是那种**增加依赖却不增加独立证据**的线索。
- **算法单一化与共享先验。** 许多下游系统继承少数预训练底座的先验；对齐/指令微调会**收窄**输出多样性。近期证据也显示 LLM 误差在提供商/架构间**相关**（尤其强模型）。
- **LLM 集成与多智能体。** 自洽采样、多智能体辩论既可能帮忙也可能**收敛到共同误解**、从众、在同侪压力下退化。

### 3.1 与最近工作的差异（novelty delta）
论文把最近几条线**并列对照**，强调各自"分别做了什么"：
- **Kim 等**：观察到 LLM 误差跨提供商**相关**（观测性质）；
- **Estornell & Liu**：**理论上**证明辩论可收敛到共同误解；
- **Yang 等**：欠规约会**降低准确率**；
- **算法单一化（Kleinberg 等）**：**系统层面**跨决策者的相关结果。

**本文则不同**：隔离一个**受控、预注册、对能力不敏感、可执行 gold 的轴——消歧信息的位置（内 / 外）**——在固定基础任务、agent、可执行验证器的前提下**把失败开关式地打开/关闭**，并把它框成一个**界面/协作中心的问题**（何时"显示的多模型一致"值得信任），用**收敛性错觉**度量，而非泛泛的误差相关或准确率。Study 2 的检测器进一步区别于基于澄清的不确定性分解（**ICE**）。落点是 **CSCW 问题**：协作系统里聚合的多模型一致何时可信。

---

## 4. 研究问题与假设

- **RQ1（regime）**：CD 是否取决于**消歧信息的位置**？预测：外部时高（**H1_external**），内嵌时近零（**H2_derivable**）。
- **RQ2（redundancy）**：加 agent 是否增加独立证据？测聚合 vs 单 agent（H1a），量化有效集成规模。
- **RQ3（capability/family）**：失败是否由弱模型或单一厂商造成？比较能力档与模型家族。
- **RQ4（dose）**：CD 是否随被删澄清子句数 k 增加（H1b）？含 k=0 全规约对照（R1a）、解释均匀零假设（R1b）、跨家族**构造**对照（R2）。

## 5. 实验设计

### 5.1 Study 1：可执行 gold 基准（executable-gold benchmark）

**任务构造**：一个任务在**删掉某个决定性子句**、使多种解读都与保留输入相容时，即为"欠规约"。每个任务固定一个目标解读 $I_0$ 与若干枚举出的**干扰项（foils）** $I_1,\dots$；答案由**可执行 `check()`** 确定性地打上"实现了哪个解读"的标签，或标为 $I_\perp$（离轴/不可解析）。**关键：正确性与解读标签独立于模型一致性判定——没有任何 LLM 当裁判。**

**三个领域的确定性 gold checker**：
- `code_spec`：把候选实现跑测试；
- `data_analysis`：比对计算结果；
- `policy_qa`：对 `{"amount": float}` 形式做精确到分的数值匹配。

**item 集合**：跨三领域重构 **54 个任务变体**——**40 个 H1_external**（消歧需外部知识）+ **14 个 H2_derivable**（消歧信息保留在 prompt 内）；每个在歧义级别 $k\in\{0,1,2,3\}$（k=0 为全规约）。item 被**反转（reversed）**，使"不知情求解者"的**自然默认**恰好是一个 foil，每个 foil 与 $I_0$ 只在一个约定轴上不同（如 日历季度 vs 财年季度；地板除 vs 向零截断）。

> **重要说明**：40 个 H1 与 14 个 H2 是**不同的 item 家族**，不是同一任务的成对最小变体，因此 H1-vs-H2 是**广义的 regime 比较**；最锋利的**因果**证据来自**同 item 内 k=0 vs k≥1 对照**（R1a，见结果），它在固定基础任务/流水线/标注器/指标下只改变"消歧子句是否保留"。

**条件（附产品化标签）**：单 agent（单模型协助）、自洽 k=5（重复采样）、同厂多数/辩论 N=5（同厂集成，$\rho\to1$ 基线）、跨家族异质辩论（跨厂比较/聚合）；次级敏感性加 SC k=10、verifier。一个"解释优先比较"条件因**可能泄漏轴**被排除在主网格外（只作次级）。

**模型阵容（三家族 × 档次）**：
| 类别 | 家族 | 模型 |
|---|---|---|
| 同厂单模型 | OpenAI | gpt-5.4 |
| 异质池 | OpenAI/Anthropic/Google | gpt-5.4 / claude-sonnet-4.6 / gemini-3.1-pro-preview |
| 推理档 | OpenAI/Anthropic/Google | gpt-5.6-sol / claude-opus-4.8 / gemini-3.1-pro-preview |
| 弱档（非前沿） | OpenAI/Anthropic/Google | gpt-4o-mini / claude-haiku-4.5 / gemini-3.5-flash |
| **主基准构造者** | Microsoft | mai-code-1-flash（**在被测池之外**） |
| R2 留出构造者 | Anthropic | claude-opus-4.8（第二个构造家族） |
| 验证/审计 | OpenAI | gpt-5.6-sol |

**主指标——收敛性错觉 CD**：一个 cell 内 $N$ 个 agent，取落在单个**众数错误（枚举内）解读**上的比例（$I_\perp$ 留在分母但不能作为收敛标签）。另报**依赖度估计量**：成对错误一致率、Fleiss $\kappa$、错误指示的组内相关 $\rho$（ICC），以及**有效集成规模** $n_{\mathrm{eff}}=n/(1+(n-1)\bar\rho)$，量化名义 $n$ 个 agent 实际提供多少**独立**判断；再加一个**独立性校准反事实** $\Delta=\mathrm{CD}_{obs}-\mathbb{E}[\mathrm{CD}_{indep}]$。一个**基于规则（非 LLM）**的检测器判断 agent 是否弃权/请求澄清。每个 cell 跑 3 个无碰撞种子。

**构造效度与防护**：
- 每个 item 通过**经验默认检查**（有能力但不知情的模型会产出 foil）与 regime 标签校验；
- **Gold 构造防护**：gold 可执行、确定性、无 LLM；54 冻结 item + R2 子集(12) + 两个次级稳健性 sidecar(64) 共 130/130 相互可区分、163 项测试通过；对抗性 foil 校验器**fail-closed**；
- **默认检查披露与效度警示**：因入选**部分以默认行为为条件**，可能抬高观察到的收敛率——用两个对照界定这个**泛化性 artifact**：① 同 item 内 k=0 全规约 → CD≈0；② H2_derivable（信息保留）→ CD≈0；
- **不过**这两个对照本身不能排除"专门筛选易出 foil 的 item 对**观察到的率**的抬高"——由**Amendment 14 无筛选样本复现**直接界定（见结果）；
- **R2 跨家族构造对照**：用第二个构造家族（Anthropic）重建 H1 子集，只在**非 Anthropic** 模型上评测。

### 5.2 Study 2：黑盒潜在前提钉住（LPP）检测器

**动机**：语义熵（$H_{\mathrm{seed}}$，对同一 prompt 重采样的熵）是 SOTA 幻觉信号，但它对"模型**自信地自洽**、答案却暗中依赖某未言明前提"的情形**系统性失明**。相关的轴不是"固定输入的采样方差"，而是**前提/上下文敏感性**。

**LPP 三步（黑盒、仅推理，无需 logit/梯度/厂商特权）**：
1. **自曝（self-surface）**：用**通用** prompt 让模型自己说出"回答前必须先定死的、决策相关的未言明假设"。prompt **绝不**提及目标解读/被删约定/枚举 foil（**anti-leakage**）。
2. **反事实钉住并聚类**：把每个自曝维度钉到模型**自己**的候选值上，用冻结基准的**可执行等价**两两比对（union-find）把钉后答案聚类；$H_{\mathrm{ctx}}$ 是答案等价簇上的熵。
3. **标记**：当 $H_{\mathrm{ctx}}>\tau \wedge H_{\mathrm{seed}}\le\tau_s$（冻结操作点 $\tau=0$、$\tau_s=0.5$ bits）时标记。

**可执行 gold-歧义标签与非循环性**：item 为 $\mathrm{AMB}{+}$ 当且仅当其**自身枚举的**至少两个解读在测试输入上产生不同可执行结果；否则 $\mathrm{AMB}{-}$。标签**由跑代码得到、绝不进任何 prompt**。评测因此**非循环**：gold 聚类的是**基准枚举的解读**，检测器聚类的是**模型自生成的钉子**——两套独立的 pin 集。54 个 item 中 **33 AMB+ / 21 AMB− / 0 不可区分**。

**基线**：语义熵 $H_{\mathrm{seed}}$、自洽、requirements-probing（只自曝不钉住）、token-logprob（仅 OpenAI 可用，跨家族不报）。

**干预（Phase 2b，从诊断到行动）**：
- **H-B1′ 选择性澄清**：把检测器当"澄清门"，只在它标记时触发澄清；比较净澄清率 = 恰当（AMB+ 上澄清，越高越好）− 过度（AMB−/k0 上澄清，越低越好）。
- **H-B2′ oracle 解析**：在一个**受控 oracle**（模拟用户，提供被删轴的 gold 约定）下，看 CD 是否被消除。**注意：这是 oracle 上界**——真实用户研究是未来工作。

## 6. 实验结果

### 6.1 Study 1 主要发现（F1–F5）

**F1 —— 省略外部上下文产生"看似准确、系统性错误"的共识。**
- H1_external：**CD = 0.53**（可解析答案中 0.60）——多数独立 agent 落在**同一个错误解读**上。
- H2_derivable：**CD = 0.00**——消歧信息在 prompt 内时，无可解析 agent 收敛到错误枚举解读。
- regime 差 **ΔCD = 0.53**，三种指标变体一致、随删除子句数 k 单调。
- **同设计操纵检查（决定性）**：k=0 全规约 CD=0.00，k≥1 CD=0.82（差值 95% CI [0.73, 0.90]）——同流水线/标注器/指标下，prompt 完整则为零、删一条即高（**R1a**），排除标注器或 foil 计数 artifact。

**F2 —— 能力与家族多样性不能恢复解释独立性。**
- H1_external 上跨模型类别**无可检测差异**：前沿推理者被困的可靠程度与弱模型相当；跨家族异质池与单模型重复采样收敛强度相当（异质 vs 同质 ΔCD=−0.003，非预测方向）。
- 事后次级**等价检验（TOST）**：跨家族≈同质在 ±0.15 与 ±0.10 均等价；推理≈弱档均等价；弱 vs 异质仅在 ±0.15 等价、±0.10 不等价（**如实标注、不夸大**）。
- 结论用词已软化为 **capability-insensitive（对能力不敏感）** 而非"不变"。

**F3 —— 加 agent 几乎不加有效冗余（fake redundancy）。**
- H1_external：成对错误一致率 **0.98**、Fleiss $\kappa$=0.97、ICC=0.89、**$n_{\mathrm{eff}}=1.10$**。
- 独立性校准反事实：观测−独立 CD = **+0.245**（95% CI [0.234, 0.257]），显著超过同准确率下真正独立 agent 会产生的收敛。
- 即"一个名义 $k$-agent 系统在此只提供约**一个有效独立判断**"。SC k=10 敏感性：$n_{\mathrm{eff}}=1.10$、ICC=0.91（加倍集成也不恢复独立性）。

**F4 —— 失败是静默的；保留消歧即消除。**
- 弃权/请求澄清率 **≈ 0.03%**，而 CD=0.53——共识不带任何内部预警。
- CD 随删除子句数 k 上升（H1b，k 系数 0.31，95% CI [0.18, 0.45]）。H2（信息保留）**完全**移除该失败。

**F5 —— 收敛不是"基准构造者"的 artifact。**
- 主基准由 Microsoft `mai-code-1-flash`（池外）构造；R2 留出子集由 Anthropic 构造（两个独立构造家族）。
- **其他家族（OpenAI、Google）**在 Anthropic 构造的 foil 上单 agent **CD=0.72**（构造有效 item 上 0.87）。
- 事后次级**跨模型集中度**：k≥1 item 上每 item 平均集中度 **0.711**（item 级 bootstrap 95% CI [0.400, 0.978]），其中 4/6 有≥2 个不同非 Anthropic 家族落在**同一个**具体错误 foil 上。
- 用词软化为 **argues against（反驳/削弱）** 而非"排除"——因为预注册的 R2 聚合放大指标本身**inconclusive**，结论转而依托上述直接的跨模型集中度与单 agent 持续性。

**稳健性与如实报告的零结果**：
- H1a（聚合放大 CD）**inconclusive**；R1b（均匀零假设）在主指标 inconclusive、在可解析答案中支持；H2 推理×能力交互**不可估计**（14 item 样本小，属估计限制而非零证据）；主效应由良好功效的 regime 主效应承担。
- **Amendment 13（regime×domain 交叉，次级稳健性）**：操纵检查先验证（H2 recovery 1.000 vs H1 0.125）；`code_spec` CD(H1)=0.887 vs CD(H2)=0.042（对比 0.846）、`policy_qa` 0.986 vs 0.042（0.944）；pooled regime 主效应 0.895，regime×domain 交互 −0.099（不显著）→ 两 regime 效应**不被领域混淆**。
- **Amendment 14（无筛选样本复现，次级稳健性）**：24 个无筛选 k=1 item，pooled 无条件 CD=**0.685**（95% CI [0.521, 0.839]），79.2% 仍收敛；相对筛选后 0.53 的点估计差 +0.155，但 0.53 落在无筛选 CI 内 → 正确结论是**未衰减**（支持 H-A14），**无证据表明筛选抬高了效应**。
- **探索性 Phase B（事后、Amendment 12）**：跨厂**合成**（C5）CD=0.567（Δ+0.023）、通用**角色多样化**工作流（C7）CD=0.575（Δ+0.031）——**两个都是如实零结果**：在共享信息边界下，改聚合配方或加通用认知角色都不降 CD，暗示（但不证明）解药须**多样化输入/证据**，而非厂商或角色。

### 6.2 Study 2 检测结果

- 全部 6 个模型（3 家族 × 2 档）上，$H_{\mathrm{ctx}}$ 远超随机、远超语义熵：**pooled AUROC = 0.895**（[0.815, 0.966]）vs 语义熵 **0.581**（[0.484, 0.675]），**ΔAUROC = 0.314**（预承诺 ≥0.15）。每模型 $H_{\mathrm{ctx}}$ 0.856–0.887、语义熵 0.551–0.606。
- **危险象限**：**25/33（0.758）** 的 AMB+ item 落在"低语义熵 × 高钉住熵"区（预承诺 ≥0.40）。冻结操作点上 pooled 精度 0.926、召回 0.758、k0 假阳 0.095。
- **如实 caveat（不夸大）**：
  1. requirements-probing 基线**本就强**（pooled AUROC 0.810）→ 钉住的增量虽真但**modest（+0.085）**；我们补了**配对 cluster-bootstrap 95% CI [0.01, 0.19]（排除 0）**坐实"真"；
  2. **localization（定位是哪个轴）弱**（pooled 0.36），是次级、召回受限信号；
  3. token-logprob 基线在非 OpenAI 模型不适用，跨家族不报。
- **表述已软化**：检测器检测的是 **fake redundancy 的潜在前提歧义（风险代理/前兆）**，而非 convergent delusion 本身。

### 6.3 Study 2 干预结果（完整 972 cells，6 模型）

**H-B1′ 选择性澄清（pooled）**：
| 策略 | 恰当(AMB+↑) | 过度(AMB−↓) | **净↑** | 危险子集覆盖 |
|---|---|---|---|---|
| **LPP-gated（本文）** | 0.741 | 0.402 | **0.339** [0.201, 0.465] | **0.741** |
| always-clarify | 1.000 | 1.000 | 0.000 | 1.000 |
| semantic-entropy-gated | 0.140 | 0.024 | 0.116 | 0.140 |
| self-consistency-gated | 0.140 | 0.024 | 0.116 | 0.140 |
| requirements-probing | 0.975 | 0.881 | 0.094 | 0.975 |

- LPP 净澄清 **0.339** 高于所有基线；**危险子集**（低 seed 熵、语义熵失明的自信潜在前提区）覆盖 **0.741 vs 语义熵 0.140**——LPP 恰在失败所在的象限触发澄清。
- **如实的跨模型细节**：门的**选择性随模型能力变化**——推理模型 gpt-5.6-sol 上很干净（过度澄清 0.032、净 0.544），pooling 较弱模型把过度澄清抬到 0.402、pooled 净降到 0.339；per-model 净从 0.149（claude-haiku-4.5）到 0.544（gpt-5.6-sol）。即 **LPP 稳定"覆盖"危险区，但"精度"依模型而定**（如实报告、不 pooling 掉）。

**H-B2′ oracle 解析**：
- 在受控 oracle（提供被删轴 gold 约定，模拟用户）下，AMB+ item 的 CD 从 never-clarify 基线 **0.626**（[0.490, 0.763]）降到 **0.010**（[0.000, 0.025]）——配对下降 **0.616**（[0.480, 0.753]），目标解读在 **94.1%** 的 item 上恢复（oracle $I_0$-hit 0.941）。
- 下降 CI 分离、跨模型稳健（6 模型中 **5 个** per-model oracle CD = 0.000）。
- **关键定性（已软化为上界）**：这是一个 **oracle 上界**——给定缺失约定，模型能恢复，故失败**非模型内在**；但 **LPP 自身的前提定位弱**，检测器**并不自主提供修复**，真实用户能否提供该约定**未测**。

## 7. 讨论

- **无认知独立性的共识**：聚合的认知担保来自独立性；在共享信息边界下，即便被聚合系统名义上异质，这种担保也**缺席**。共识此时度量的是**共享先验的集中度**，而非独立证据的佐证。
- **是"共享输入失败"，而非 groupthink**：结果形似群体思维（一致、自信的错误），但机制不同——本文 agent 在主条件下**不通信**却仍收敛。这是一条**共享输入/表示单一化**的独立通路，出现在任何交互**之前**；针对 groupthink 的干预（唱反调、结构化异议）对它无效。
- **信息丢失是一种社会技术失败**：决定性信息在 handoff 处丢失（grounding-resource boundary），下游聚合无法找回；问题在**流水线**、不在模型。

## 8. 面向多模型界面的设计启示（6 条，框为 implications/hypotheses，非已验证干预）

1. **展示"依赖感知的共识面板"，而非 agent 计数**：把"4/4 一致"替换为报告"答案能否被当作独立证据"的面板（共享输入 / 上下文完整性 / 共同解读 + 至少一个替代解读 / 建议动作=先索要缺失约定）。因为 agent 自己很少发问（对应 F4 静默），界面/设计者**应**内建这种澄清寻求。
2. **先聚合"解读"，再聚合"答案"**，并**保留异议通道**，而非强行早收敛。
3. **按上下文完整性路由**：当共识高**但**上下文完整性不确定时触发人工复核。
4. **多样化证据与解读，而非仅换厂商**：视角多样性可能需要多样的**输入/检索/表示**——换厂商留着同一个盲点（探索性 Phase B 与此一致）。
5. **跨 handoff 保留 provenance**，别静默丢弃消歧所需的上下文。
6. **审计解释单一化**：在"机群"层面审计，而非只看单模型准确率。

## 9. 局限、伦理与开放科学

- **无真人研究**：任务单回合、非交互；关于人类信任/团队/高风险场景的说法是**implications 而非已验证部署**。这是投稿最大的可攻击点（三份独立审计一致点名），也是本文诚实标注的未来工作。
- **构造效度**：反转基准 + 默认检查；两个 item foil 集不完整，由预注册 drop-$I_\perp$ 敏感性处理；因入选部分以默认检查为条件，**不估计真实世界发生率（prevalence）**——本文**刻画并检测一种失败模式**，而非它多常见。
- **oracle 上界**：H-B2′ 的"修复"依赖模拟用户提供 gold 约定；真实用户效果未测。
- **弃权检测器**为基于规则、待人工验证。
- **诚信**：预注册 + 冻结指标；跨家族对抗审计（实现方 ≠ 审计方家族）；所有标签源自确定性可执行 gold；如实报告零结果与 inconclusive；**报告数据完整**（Study 2 干预为完整 972/972 cell）。
- **伦理**：无人类被试；数据均为模型对合成基准任务的响应；无个人/敏感/版权材料；主要发布风险为 dual-use（发布"陷阱"基准可能被用于过拟合"显得稳健"）——通过发布**可执行构造流程**（而非静态排行榜）缓解。

## 10. 贡献总结

1. **概念与交互范式**：指出同题多模型界面里"跨模型一致=独立佐证"的隐藏假设，命名 **fake redundancy**；landscape 审计显示这类界面普遍提供比较/共识/合成，却很少提示"所有模型共享同一份、可能残缺的输入"。
2. **实证**：预注册证据——独立查询的 LLM agent（跨能力档 + 三家族）在关键消歧被从共享 prompt 删除时**静默收敛到同一错误解读**，而消歧存在时该失败消失；对能力不敏感、跨家族。
3. **方法**：一套**可执行 gold** 协议，操纵消歧是否跨越 prompt 边界并度量**相关误差**（而非仅个体准确率），正确性独立于模型一致性、无 LLM 裁判；用经典估计量（成对一致、ICC、$n_{\mathrm{eff}}$）刻画"名义 $k$-agent 何时只提供约 1 个有效独立判断"。
4. **设计**：依赖感知的多模型界面**概念**与设计启示（评估留作未来工作）。
5. **黑盒检测器（Study 2）**：把检测从"同输入重采样"转到正交的**前提敏感性**轴；在可执行 gold-歧义上，黑盒跨厂 LPP 检测器以 **AUROC 0.895 vs 0.581** 分开歧义/非歧义（语义熵失明处），并使检测→行动闭环成为可能；如实 ablation（自曝已贡献大部分信号、钉住加 +0.085 且 CI 排除 0、定位弱）。
